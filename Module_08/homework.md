## Что нужно сделать

### 1. Изучить материалы и пройти квиз

- Пройти квиз модуля на https://quiz.sekachev.ee.

### 2. Сделать простого голосового ассистента

Сделайте небольшого ассистента, с которым можно пообщаться голосом.

Самый удобный вариант - Telegram-бот: пользователь отправляет голосовое сообщение, бот понимает запрос и возвращает ответ. Ответ может быть текстом или голосом.

Можно выбрать один из двух путей:

- `STT -> LLM -> TTS`: голос превращается в текст, языковая модель готовит ответ, TTS озвучивает ответ;
- `LLM -> TTS`: пользователь пишет текстом, языковая модель отвечает, TTS озвучивает ответ.

Если получится сделать ответ только текстом после голосового сообщения, это тоже принимается как базовый вариант. Главное - показать, что голосовой ввод или голосовой вывод реально работает.

Задайте ассистенту простую роль.

Примеры ролей:

- ассистент салона красоты, который отвечает на вопросы и предлагает запись;
- консультант учебного курса;
- помощник интернет-магазина;
- секретарь маленькой компании;
- тренер по английскому;
- голосовой помощник для вашей CRM или SMM-проекта.

Минимальные требования:

- есть понятная роль ассистента;
- ассистент принимает голосовое сообщение или умеет отвечать голосом;
- используется LLM для ответа;
- есть короткий тестовый диалог из 3-5 реплик;
- проект опубликован в публичном GitHub-репозитории;
- в `README.md` описано, как запустить проект и какие переменные окружения нужны;
- настоящие API-ключи, токены и `.env`-файлы не опубликованы.

Дополнительно, если успеете:

- сделать полный путь `STT -> LLM -> TTS`;
- добавить ограничение доступа по Telegram ID;
- сохранять транскрипт и ответ в файл или базу данных;
- добавить короткое summary диалога;
- сравнить два варианта: STT+LLM и прямую работу мультимодальной модели с аудио;
- подключить ассистента к своему проекту, CRM или базе знаний.

Телефонию, Twilio, звонки из браузера и full-duplex голосового робота делать не обязательно. Это можно оставить как задание со звёздочкой.

### 3. Задание со звёздочкой

Если базовый ассистент уже работает, можно попробовать один из вариантов:

- подключить Twilio или другой телефонный сервис;
- сделать запись звонка и транскрибацию;
- добавить страницу с историей голосовых диалогов;
- сделать ассистента с более живым стилем речи: темп, интонация, короткие фразы;
- добавить function calling: например, ассистент может создать заявку, найти клиента или записать задачу.

Это задание необязательное.

## Критерии готовности

Домашняя работа считается готовой, если:

- выбран простой сценарий и роль ассистента;
- ассистент использует LLM;
- есть голосовой ввод или голосовой вывод;
- есть тестовый диалог из 3-5 реплик;
- проект запускается локально;
- есть `README.md` с инструкцией запуска;
- секреты не опубликованы в репозитории;
- проект опубликован в публичном GitHub-репозитории;
- отчёт отправлен через учебного агента.
