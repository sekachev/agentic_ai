# Конспект лекции: Автоматизация SMM и создание ИИ-агентов для бизнеса

## 1. Введение: Новая эра автоматизации
Современный SMM переходит от ручного управления к созданию **автоматизированных экосистем**. Цель — не просто заменить человека, а создать «виртуальный отдел маркетинга», который способен анализировать базу знаний компании, следовать стратегии и генерировать контент 24/7.

---

## 2. Технический фундамент: Meta API и Instagram
Для того чтобы ИИ мог самостоятельно публиковать посты или читать комментарии, необходимо настроить связь с платформой через API.

### 2.1 Настройка Meta для разработчиков
1. **Создание приложения:** На портале [Meta for Developers](https://developers.facebook.com/) создается приложение (тип: Business или Content Publishing).
2. **Ограничения:** API Meta работает только с **бизнес-аккаунтами** Instagram или аккаунтами авторов, привязанными к странице Facebook.
3. **Разрешения (Scopes):**
   - `instagram_basic` — получение информации.
   - `instagram_content_publish` — публикация постов и Reels.
   - `instagram_manage_comments` — работа с комментариями.

### 2.2 Работа с токенами (Access Tokens)
Ключевая сложность — безопасность и долговечность доступа.
*   **Краткосрочные токены:** Живут несколько часов.
*   **Долгосрочные токены (Long-Lived Tokens):** Живут **60 дней**. 
*   **Скрипт обновления:** Рекомендуется использовать Python-скрипт, который автоматически обменивает краткосрочный токен на долгосрочный, чтобы система не «падала» каждые два дня.

## 3. Структурирование данных: «Мозг» системы
ИИ не может работать в вакууме. Ему нужна **База знаний** (Knowledge Base), оформленная в виде структурированной базы данных (например, **SQLite**).

### 3.1 Сущности базы данных:
1.  **Knowledge Base (База знаний):** Общая информация о компании, миссия, Tone of Voice (стиль общения), целевая аудитория (ЦА).
2.  **Courses & Teachers (Курсы и преподаватели):** Детальное описание продуктов (например, курсы поваров, флористов), биографии экспертов.
3.  **Strategy (Стратегия):** Глобальные цели на год/квартал.
4.  **Content Plan (Контент-план):** Еженедельные «атомарные» задачи. Каждая неделя имеет свою тему (например, «Неделя открытых дверей»).
5.  **Posts (Посты):** Архив уже опубликованных и запланированных материалов (Текст, ссылка на медиа, дата, статус публикации).

## 4. Виртуальные сотрудники: ИИ-агенты
В лекции рассматривается концепция агентов, которые имеют свои роли и инструменты.

### Агент «Клешня» (Clo / OpenClo)
Это автономный виртуальный сотрудник, живущий на сервере (например, на **Raspberry Pi** или VPS).
*   **Интерфейсы:** Может общаться через Telegram, почту (Gmail API) или внутренние чаты.
*   **Инструменты:** Имеет доступ к терминалу, базе данных и внешним API (OpenRouter, Gemini, OpenAI).
*   **Логика:** Агент не просто выдает текст, он «думает»: *«Так, сегодня понедельник, тема недели — курсы поваров. В базе знаний написано, что преподаватель — Андрей. Пойду посмотрю его фото в архиве и напишу пост в его стиле»*.

## 5. Контент-пайплайн: От идеи до публикации

### Шаг 1: Сбор информации (Scraping & Parsing)
Использование инструментов вроде **Instaloader** или кастомных парсеров на Python для сбора информации с сайта компании (например, `profteh.ee`) и анализа старых постов. Это позволяет ИИ понять контекст.

### Шаг 2: Генерация текста
ИИ-агент обращается к языковой модели (LLM) через **OpenRouter** (позволяет менять модели: GPT-4, Claude, Gemini без переписывания кода).
*   **Двуязычность:** Для Эстонии актуальна генерация на эстонском и русском в одном посте.

### Шаг 3: Визуальный ряд
*   **Хранение:** Meta API принимает только прямые ссылки на изображения. Нужно загрузить картинку на сервер (VPS) и передать API ссылку.
*   **Генерация:** Использование DALL-E 3 или Midjourney API для создания уникальных обложек.

## 6. Видео-контент и программный монтаж
Будущее SMM — автоматизированное видео.

1.  **Manim (Math Animation Engine):** Популярный инструмент (как у канала *3Blue1Brown*) для создания математических и логических анимаций через код Python.
2.  **Remotion:** Инновационный фреймворк для создания видео с использованием **React**. 
    *   Видео описывается кодом.
    *   Позволяет автоматически подставлять текст, менять картинки и рендерить сотни уникальных роликов по шаблону без участия монтажера.

## 7. Риски и безопасность
*   **Теневой бан:** Instagram не любит автоматизацию через «серые» методы (эмуляция браузера). Использование официального Graph API минимизирует риски.
*   **Человеческий контроль (Human-in-the-loop):** Рекомендуется стадия **Approval** (одобрение). Агент создает черновик поста и присылает его в Telegram куратору. Только после нажатия кнопки «Одобрить» пост уходит в Instagram.
*   **Конфиденциальность:** Не передавайте личные пароли в открытом коде. Используйте переменные окружения (`.env`) и «Пароли приложений» Google для работы с почтой.

## 8. Итоги и вдохновение
Для того чтобы построить качественную систему, нужно пройти путь от простого к сложному:
1.  **Официант/Повар:** Сначала научитесь делать всё вручную (понимать механику API, писать промпты).
2.  **Администратор:** Настройте структуру базы данных и логику процессов.
3.  **Владелец:** Запустите агентов, которые будут управлять этой структурой за вас.

**Рекомендуемые каналы для изучения визуального контента:**
*   *Veritasium* — пример глубокого образовательного контента.
*   *3Blue1Brown* — мастерство визуализации сложных концептов через код.
