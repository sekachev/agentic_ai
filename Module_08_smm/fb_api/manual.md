
### Шаг 1. Настройка аккаунтов
Обычный личный профиль не имеет API. Его нужно превратить в «рабочий инструмент».
1. Открой настройки своего Instagram. Переведи аккаунт в статус **Business** (Бизнес) или **Creator** (Автор). Это бесплатно.
2. Создай публичную страницу в Facebook (Facebook Page). Она может быть пустой, она нужна просто как «технический узел».
3. В настройках этой страницы Facebook найди раздел «Связанные аккаунты» и привяжи туда свой Instagram.

### Шаг 2. Создание приложения в Meta
Теперь нужно заявить системе, что ты разработчик.
1. Зайди на портал Meta for Developers.
2. Создай новое приложение. Тип приложения обязательно выбирай **«Other»** (Другое), а на следующем экране — **«Business»** (Бизнес).
3. Придумай название и заверши создание.
4. В панели управления приложением найди раздел «Добавить продукт» и выбери **Instagram Graph API**.

### Шаг 3. Получение данных через Explorer
Meta предоставляет инструмент Graph API Explorer для тестов.
1. Открой Explorer. В выпадающем меню справа выбери свое созданное приложение.
2. Нажми кнопку «Get Token» и выбери **Get User Access Token**.
3. Тебе нужно проставить галочки (разрешения). Это критически важно:
   * `instagram_basic` — чтобы видеть профиль.
   * `instagram_content_publish` — чтобы постить.
   * `instagram_manage_comments` — чтобы отвечать.
   * `pages_show_list` и `pages_read_engagement` — чтобы видеть связь со страницей Facebook.
4. После того как ты нажмешь «Generate Access Token» и подтвердишь всё в сплывающих окнах, у тебя появится длинная строка — это твой временный **Access Token**.

### Шаг 4. Узнаем ID через запрос
В строке запроса в Explorer (там, где написано `me?fields=id,name`) введи следующее:
`me/accounts?fields=name,id,instagram_business_account`

Нажми Submit. В ответе ты увидишь:
1. `id` — это твой **Facebook Page ID**.
2. `instagram_business_account` -> `id` — это твой **Instagram Business ID**.
Сохрани их в блокнот.

### Шаг 5. Делаем токен «вечным»
Токен из Explorer живет пару часов. Чтобы скрипт работал долго, нужно обменять его на 60-дневный.
Отправь GET-запрос по такому адресу (можно просто вставить в строку браузера, подставив свои данные):
`https://graph.facebook.com/oauth/access_token?grant_type=fb_exchange_token&client_id=ТВОЙ_APP_ID&client_secret=ТВОЙ_APP_SECRET&fb_exchange_token=ТВОЙ_ВРЕМЕННЫЙ_TOKEN`

*APP ID и APP SECRET можно найти в настройках твоего приложения в Meta (раздел Settings -> Basic).*
