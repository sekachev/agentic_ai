## Вариант А: приложение для генерации SMM-креативов по шаблону

Сделайте небольшое приложение или скрипт, который генерирует SMM-креативы по заранее заданному шаблону.

Идея: есть шаблон, текст, картинка или фото, а программа собирает из них готовый креатив для соцсетей.

Формат можно выбрать простой:

- Instagram Story или Reels cover: `1080x1920`;
- квадратный пост: `1080x1080`;
- карточка для Telegram, LinkedIn или другого канала.

Примеры проектов:

- генератор сторис для салона красоты;
- генератор карточек товаров;
- генератор афиш мероприятий;
- генератор SMM-креативов для учебного курса;
- генератор постов для недвижимости;
- генератор обложек для Reels или YouTube Shorts.

Минимальные требования:

- есть один переиспользуемый шаблон;
- в шаблон подставляется текст;
- в шаблон подставляется изображение или фото;
- можно сгенерировать минимум 3 разных креатива;
- текст не обрезается и не налезает на важные элементы;
- результат сохраняется как PNG, JPG или другой понятный формат;
- проект опубликован в публичном GitHub-репозитории;
- в `README.md` описано, как запустить проект и как создать новые креативы.

Что можно использовать:

- HTML/CSS + скриншот;
- Canvas;
- Python Pillow;
- Canva как источник макета, если сборка результата автоматизирована отдельно;
- любой другой инструмент, если результат можно воспроизвести.

Дополнительно, если успеете:

- добавить несколько шаблонов;
- добавить выбор цветов, шрифтов или логотипа;
- сделать безопасную зону для текста под Stories/Reels;
- добавить хромакей-зону или отдельную область для фото;
- добавить генерацию текста через LLM;
- сделать простой веб-интерфейс.

## Вариант Б: генерация видео с помощью Remotion или FFmpeg

Сделайте короткий вертикальный ролик или автоматическую сборку видео.

Идея: программа берёт текст, изображения, видеофрагменты, музыку или субтитры и собирает из них готовый ролик.

Формат:

- вертикальное видео `1080x1920`;
- длительность 5-20 секунд;
- результат в `mp4` или другом видеоформате.

Примеры проектов:

- короткий рекламный ролик для продукта или услуги;
- Reels/Shorts с текстовыми сценами и картинками;
- видео из нескольких изображений с музыкой;
- ролик с субтитрами;
- авто-нарезка одного видео на короткий фрагмент;
- видео-презентация для учебного проекта.

Минимальные требования:

- используется Remotion или FFmpeg;
- видео создаётся программно, а не только вручную в редакторе;
- есть минимум 3 сцены, кадра или смысловых блока;
- есть текст на экране, субтитры или титры;
- итоговый ролик сохраняется как видеофайл;
- проект опубликован в публичном GitHub-репозитории;
- в `README.md` описано, как запустить генерацию видео.

Что можно использовать:

- Remotion для анимации, титров, сцен и программной графики;
- FFmpeg для склейки, нарезки, наложения музыки, субтитров или конвертации;
- сгенерированные изображения;
- свои фото, видео или аудио;
- музыку только с учётом лицензии.

Дополнительно, если успеете:

- добавить музыку или озвучку;
- добавить субтитры из `.srt` или простого текстового файла;
- сделать несколько вариантов ролика из одного шаблона;
- добавить данные из JSON или Markdown;
- сделать автоматическую нарезку длинного видео;
- добавить генерацию изображений или текста через AI.
