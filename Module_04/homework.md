# Домашняя работа: мультиагентные системы плюс практика

## Цель

Собрать собственного учебного агента в новом проекте, разобраться с памятью агента, локальными скиллами, GitHub и публикацией результата в открытом репозитории.

## Что сделать

### 1. Создать агента в новом проекте через Codex

Создайте новый отдельный проект и с помощью Codex соберите в нём агента.

У агента должны быть:

- память по сессиям;
- долгосрочная память;
- понятный процесс переноса данных из сессионной памяти в долгосрочную;
- один собственный локальный скилл.

Важно: не обязательно делать сложную production-систему. Главное, чтобы было видно, как агент хранит информацию, что относится к текущей сессии, что попадает в долгосрочную память и как это переносится.

### 2. Инициализировать GitHub

В папке проекта нужно:

- инициализировать Git;
- авторизоваться в GitHub-плагине в Codex;

### 3. Запушить проект в публичный репозиторий

Опубликуйте проект в публичном репозитории на GitHub.

Репозиторий должен содержать:

- контекст агента - AGENTS.md и тд;
- описание проекта README.md;
- логика работы памяти;
- локальный скилл;

## Что прислать

Домашнее задание и отчёт нужно прислать, как обычно, с помощью своего учебного агента.

В отчёте обязательно должна быть ссылка на публичный репозиторий на GitHub-странице студента.

## Формат отчёта

```markdown
# Отчёт по домашней работе: Модуль 4

## Студент
Имя: ...

## Проект
- Название проекта: ...
- Ссылка на публичный GitHub-репозиторий: ...

## Агент
- Что делает агент: ...
- Как запустить агента: ...

## Память
- Где хранится память сессии: ...
- Где хранится долгосрочная память: ...
- Как данные переносятся из сессии в долгосрочную память: ...

## Локальный скилл
- Название скилла: ...
- Что делает скилл: ...
- Где находится файл скилла в проекте: ...

## GitHub
- Git инициализирован: да / нет / частично
- GitHub-плагин в Codex авторизован: да / нет / частично
- Проект запушен в публичный репозиторий: да / нет / частично

## Что получилось
- ...

## Что было сложно
- ...

## Вопросы преподавателю
- ...
```

## Критерии готовности

Домашняя работа считается готовой, если:

- создан новый проект с агентом;
- у агента есть память по сессиям;
- у агента есть долгосрочная память;
- описан или реализован перенос данных из сессионной памяти в долгосрочную;
- создан хотя бы один локальный скилл;
- проект опубликован в публичном GitHub-репозитории;
- в отчёте есть рабочая ссылка на публичный репозиторий;
- отчёт отправлен через учебного агента.
