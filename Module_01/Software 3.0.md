## Software is eating the world. 

+ **Software становится ядром бизнеса**, а не просто вспомогательным инструментом.
+ **Традиционные отрасли перестраиваются цифровыми компаниями**: книги — Amazon, видео — Netflix, музыка — Spotify/iTunes.
+ **Главное конкурентное преимущество смещается в код, данные, платформы и скорость разработки.**
+ **Каждая компания должна готовиться к тому, что её отрасль будет “съедена” софтом — или стать тем, кто ест первым.**
