# Домашняя работа: модуль 6

## Что нужно сделать

### 1. Изучить материалы и пройти квиз

- Посмотреть и изучить материалы модуля 6.
- Пройти квиз модуля на https://quiz.sekachev.ee.

### 2. Создать веб-приложение с базой данных

Сделайте небольшое веб-приложение, которое хранит данные в базе данных и показывает их через веб-интерфейс.

За основу можно взять проект, который мы делали в классе. Данные могут быть любыми.

Примеры тем:

- каталог товаров;
- список клиентов;
- база заявок;
- заметки;
- список задач;
- библиотека книг;
- база мероприятий;
- CRM для простого бизнеса.

Минимальные требования:

- есть база данных;
- есть таблица или коллекция с данными;
- можно добавить новую запись;
- можно посмотреть список записей;
- можно открыть одну запись отдельно или увидеть её подробности в списке;
- проект запускается локально;
- в проекте есть `README.md` с инструкцией запуска.

Дополнительно, если успеете:

- редактирование записей;
- удаление записей;
- поиск или фильтр;
- простая авторизация;
- деплой на VPS или другой хостинг.

### 3. Опубликовать проект

Опубликуйте проект в публичном репозитории на GitHub.

Репозиторий должен содержать:

- исходный код приложения;
- файл `README.md`;
- описание, какая база данных используется;
- инструкцию, как запустить проект локально;
- пример данных или инструкцию, как создать первые записи.

## Что прислать

Домашнее задание и отчёт нужно прислать, как обычно, с помощью своего учебного агента.

В отчёте обязательно должна быть ссылка на публичный GitHub-репозиторий.

Если проект задеплоен, добавьте также ссылку на работающее приложение.

## Критерии готовности

Домашняя работа считается готовой, если:

- создано веб-приложение;
- приложение использует базу данных;
- можно добавить новую запись;
- можно посмотреть сохранённые записи;
- проект запускается локально;
- есть `README.md` с инструкцией запуска;
- проект опубликован в публичном GitHub-репозитории;
- в отчёте есть ссылка на репозиторий;
- отчёт отправлен через учебного агента.
