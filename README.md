# Tetkool AI

Актуальная рабочая папка курса по `Business Automation`.

В корне лежит только текущая версия курса:

- `Module_01` ... `Module_10` — актуальные модули текущего потока
- `PROGRAM.md` — единая программа курса
- `SCHEDULE.md` — актуальное расписание
- `archive/` — архив предыдущих потоков

## Архив

В архив вынесены предыдущие версии курса:

- `archive/tetkool-ai-2026-01-BA/` — первый поток, Business Automation
- `archive/tetkool-ai-2026-01-SMM/` — первый поток, SMM
- `archive/tetkool-ai-2026-02/` — второй поток

Архивные папки сохраняют историческую структуру модулей и связанные документы потока.

## Принцип работы

1. Корень обновляется только под текущую программу.
2. Старые потоки не редактируются в корне, а хранятся в `archive/`.
3. Если структура или содержание курса меняются существенно, предыдущая версия сначала фиксируется в архиве.
