# Модуль 5: Deployment & DevOps 🚀

Этот модуль посвящен практическому деплою AI-приложений на VPS с использованием современных инструментов и подходов.

## 📚 Содержание модуля

### 01. [Шпаргалка по Ubuntu Terminal](01_Шпаргалка%20по%20Ubuntu%20Terminal.md)
- Навигация в терминале (ls, cd, pwd)
- Работа с файлами и папками
- Редактор Nano
- Управление системными службами
- Полезные хоткеи (Tab, Ctrl+R, Ctrl+C)

### 02. [IP, DNS и Проксирование](02_IP,%20DNS%20и%20Проксирование.md)
- IP-адрес как "почтовый индекс" сервера
- DNS - телефонная книга интернета
- Nginx как Reverse Proxy (швейцар)
- Настройка server blocks
- SSL/HTTPS через Certbot
- Полная схема от браузера до сервера

### 03. [Деплой Frontend через Cockpit](03_Деплой%20Frontend%20через%20Cockpit.md)
- Локальная сборка проекта (npm run build)
- Настройка base URL в vite.config.js
- Загрузка файлов через Cockpit Navigator
- Структура папок `/var/www/html`
- Проверка работоспособности

### 04. [FastAPI - от теории к практике](04_FastAPI%20-%20от%20теории%20к%20практике.md)
- **Теория:** Аналогия "Ресторан-Официант-Кухня"
- **Почему FastAPI:** Скорость, строгость типов, автодокументация
- **Swagger UI:** Интерактивная документация `/docs`
- **Практика:** Создание `main.py` с реальным кодом
- **Установка:** pip install fastapi uvicorn
- **Тестовый запуск:** Проверка работы API
- **Systemd:** Превращение скрипта в системную службу
- **Анатомия .service:** Разбор конфигурации
- **Запуск и отладка:** systemctl, journalctl, логи
- **Практическое задание:** Модификация кода

## 🎯 Цели обучения

После прохождения этого модуля студенты научатся:
- Понимать архитектуру клиент-серверного взаимодействия
- Уверенно работать в Ubuntu Terminal
- Разбираться в сетевой инфраструктуре (IP, DNS, Nginx)
- Настраивать reverse proxy для множественных приложений
- Разворачивать backend API как системную службу
- Деплоить frontend приложения на VPS
- Отлаживать проблемы через логи и документацию

## 🛠 Используемые технологии

- **Backend**: Python, FastAPI, Uvicorn
- **Frontend**: Vite, React (опционально)
- **DevOps**: Systemd, Cockpit, Ubuntu/Debian
- **Networking**: Nginx (Reverse Proxy), DNS, SSL/HTTPS (Certbot)
- **Протоколы**: HTTP/HTTPS, REST API

## 💡 Философия модуля

> "Не нагружаем сервер сборкой — делаем build локально, загружаем готовые файлы"

Фокус на практическом понимании процесса деплоя, а не на заучивании команд. Студенты учатся мыслить системно: от кода до живого сайта в продакшене.
