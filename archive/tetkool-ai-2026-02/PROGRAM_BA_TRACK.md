## 📖 Модуль 9: Безопасная инфраструктура
**4 ак.ч. лекция + 4 ак.ч. самостоятельная работа | Специализация BA**

### Теория:
- **Git и GitHub:**
  - `git add .`, `git commit -m`, `git push`
  - GitHub Actions: CI/CD
- **MCP (Model Context Protocol):**
  - Унифицированное подключение инструментов
  - Примеры: реестры, Google Drive, Stripe
- **Skills:**
  - Skill = Инструкция + Контекст + Инструменты
- **Безопасность:**
  - Сетевая архитектура: Firewall, LAN
  - Raspberry Pi: локальный сервер (~€100)
  - Разделение кода и данных
  - Бэкапы: Google Drive, S3

### Архитектура системы:
```
Пользователь → Telegram → Raspberry Pi → AI-Агент → MCP → База Данных
                                     ↓
                              Human-in-the-loop
```

### Практика:
- Настройка Git и GitHub
- Создание Skill-файлов
- Установка Raspberry Pi
- Настройка бэкапов
