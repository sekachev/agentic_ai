### 2. Создать сайт локально

Создайте сайт на `Astro + Vite` и проверьте, что он запускается локально.

Требования к сайту:

- хранить контент в `.md`-файлах;
- сделать несколько однотипных карточек или страниц, которые собираются из markdown-контента  + `frontmatter`.

Можно использовать такой промпт:

```text
Давай создадим сайт на astro + vite

сайт по медитации - с персональными страничками тренеров

страничка каждого тренера в md + frontmater

используй tailwind сделай в пастельных тонах
```
