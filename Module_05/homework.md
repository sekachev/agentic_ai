# Домашняя работа: модуль 5

## Что нужно сделать

### 1. Изучить материалы и пройти квиз

- Посмотреть и изучить материалы модуля 5.
- Пройти квиз модуля на https://quiz.sekachev.ee.

### 2. Создать сайт локально

Создайте сайт на `Astro + Vite` и проверьте, что он запускается локально.

Требования к сайту:

- использовать `Tailwind`;
- сделать спокойный визуальный стиль в пастельных тонах;
- хранить контент в `.md`-файлах;
- сделать несколько однотипных карточек или страниц, которые собираются из markdown-контента;
- для каждой персональной страницы использовать `.md` + `frontmatter`.

Можно использовать такой промпт:

```text
Давай создадим сайт на astro + vite

сайт по медитации - с персональными страничками тренеров

страничка каждого тренера в md + frontmater

используй tailwind сделай в пастельных тонах
```

### 3. Задеплоить сайт на свой VPS

После дополнительной инструкции в Telegram задеплойте сайт на свой VPS.

В результате должна быть публичная ссылка на работающий сайт.
