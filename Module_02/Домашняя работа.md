# Домашняя работа: системный промпт, контекст, температура и функции

## Цель

Проверить, что студент понял основные идеи занятия про LLM, API и агентов:

- как системный промпт меняет поведение модели;
- что такое контекст модели и почему он ограничен;
- как температура влияет на ответы;
- зачем нужны function calling и внешние инструменты;
- как агент должен фиксировать результат работы студента.

## Задание для студента

### 1. Проверь три системных промпта

Выбери одну простую тему, например:

- объяснить термин из курса;
- помочь написать короткий текст;
- составить план небольшой задачи;
- ответить на вопрос по твоей профессии или проекту.

Затем отправь один и тот же пользовательский запрос с тремя разными системными промптами:

1. `Ты строгий технический преподаватель. Отвечай кратко, структурно и проверяй точность терминов.`
2. `Ты дружелюбный наставник для новичка. Объясняй простыми словами и приводи аналогии.`
3. `Ты практический ассистент. Сразу давай применимый результат: список шагов, чеклист или готовый шаблон.`

Зафиксируй:

- какой системный промпт дал самый полезный ответ;
- чем отличались стиль, структура и глубина ответов;
- где модель начала добавлять лишнее или терять точность.

### 2. Вызови три функции

Попроси агента выполнить три действия через доступные функции или инструменты. Подойдут такие варианты:

1. Найти актуальную информацию через веб-поиск.
2. Прочитать или создать локальный файл.
3. Посчитать, сравнить или преобразовать данные.
4. Получить данные из внешнего источника, если такой инструмент доступен.

Для каждого вызова зафиксируй:

- какой запрос ты дал агенту;
- какую функцию или инструмент агент использовал;
- какой результат вернулся;
- как модель использовала результат функции в финальном ответе.

### 3. Ответь агенту на короткие вопросы

После практики агент должен задать студенту 5-6 вопросов. Вопросы нужны не для экзамена, а чтобы проверить понимание без перегруза.

Рекомендуемые вопросы:

1. Какую информацию можно передавать языковой модели в запросе: только текст или ещё что-то?
2. Почему длинный диалог постепенно становится дороже и сложнее для модели?
3. Что происходит, если в контекст модели положить слишком много информации?
4. Как низкая и высокая температура меняют ответы модели? Для каких задач лучше низкая температура?
5. Чем системный промпт отличается от обычного пользовательского запроса?
6. Что такое function calling простыми словами и зачем агенту нужны функции?

Агент может задать уточняющий вопрос, если ответ студента слишком общий или противоречивый.

## Инструкция для агента

Ты проверяешь домашнюю работу студента по модулю 2. Работай спокойно и поддерживающе: задача не поймать ошибку, а понять, где студент действительно разобрался, а где ему нужна помощь.

### Что нужно сделать

1. Попроси студента показать результаты эксперимента с тремя системными промптами.
2. Попроси показать три запроса, которые должны были вызвать функции.
3. Задай 5-6 вопросов из блока выше.
4. Если студент отвечает слишком кратко, попроси один пример.
5. Не задавай больше двух уточняющих вопросов подряд.
6. В конце подготовь отчёт для преподавателя.

### На что смотреть

Оцени понимание по четырём направлениям:

- **Системный промпт**: студент видит, что он задаёт роль, стиль, ограничения и формат ответа.
- **Контекст и токены**: студент понимает, что модель получает ограниченный объём информации, а длинная история увеличивает стоимость и риск потери деталей.
- **Температура**: студент отличает стабильные задачи от творческих и понимает риск галлюцинаций при высокой температуре.
- **Function calling**: студент понимает, что модель сама не выполняет действия, а просит приложение или агента вызвать инструмент и вернуть результат в контекст.

### Формат отчёта преподавателю

Отправь отчёт в таком формате:

```markdown
# Отчёт по домашней работе: Модуль 2

## Студент
Имя: ...

## Что студент сделал
- Системные промпты: выполнено / частично / не выполнено
- Три функции: выполнено / частично / не выполнено
- Ответы на вопросы: выполнено / частично / не выполнено

## Понимание темы
- Системный промпт: хорошо / средне / нужно повторить
- Контекст и токены: хорошо / средне / нужно повторить
- Температура: хорошо / средне / нужно повторить
- Function calling: хорошо / средне / нужно повторить

## Сильные стороны
- ...

## Где есть пробелы
- ...

## Рекомендация преподавателю
Коротко: что студенту стоит повторить или какую практику дать дальше.
```

## Критерии готовности

Домашняя работа считается принятой, если студент:

- протестировал три разных системных промпта на одном и том же запросе;
- показал три запроса, где агент использовал функции или инструменты;
- своими словами объяснил контекст, температуру, системный промпт и function calling;
- получил от агента короткий отчёт для преподавателя.
