# SMM Content System (Markdown-centric)

Система управления контентом и знаниями на базе Markdown. Все данные хранятся локально, что позволяет легко редактировать их вручную или с помощью AI.

## Структура проекта

- `knowledge/` — База знаний (стратегия, данные о курсах и учителях).
- `content/` — Операционный контент, разделенный по неделям и дням.
- `config/` — Промпты для LLM и системные настройки.

## Организация контента

Контент организован по принципу "Папка недели -> Папка дня -> Посты и Медиа".

1. **Неделя**: `content/weeks/YYYY-WW/` (содержит `plan.md`).
2. **День**: `content/weeks/YYYY-WW/YYYY-MM-DD/`.
3. **Пост**: Все файлы поста (`.md` и картинки/видео) лежат в папке соответствующего дня.

## Воркфлоу

1. Помещение инфоповода в `content/raw_events/`.
2. Создание плана недели `plan.md`.
3. Генерация `.md` файлов постов в папках дней. Статус поста управляется через YAML Frontmatter.
4. Добавление медиа-файлов в ту же папку, где лежит текст поста.
