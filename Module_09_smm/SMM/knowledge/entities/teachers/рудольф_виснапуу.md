# Рудольф Виснапуу

## Биография (RU)
Известный шеф-повар, победитель международных конкурсов, обладатель ордена Le Gordon Bleu. Адепт молекулярной гастрономии. Неоднократно готовил для звёзд мирового масштаба, политиков и известных деятелей, его творения подают на президентских приемах. Ему доводилось готовить для самой королевы Англии. Действующий президент Ассоциации Шеф поваров Эстонии, организатор конкурса «Лучший шеф-повар Эстонии».
