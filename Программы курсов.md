### Модуль 6: Мультимодальность: Vision и OCR
**6 ак.ч. лекция + 4 ак.ч. самостоятельная работа**

#### Теория:
- Фундаментальные модели: объединение текста и изображений
- Механизм "нарезки": патчи 16×16, позиционные эмбеддинги
- Мультиголовое внимание: связи между участками изображения
- Распознавание (Чукча-читатель):
  - OCR: извлечение текста из сканов
  - Анализ документов: счета, бланки, PDF
  - Медицина: анализ селфи, оценка состояния кожи
- Генерация (Чукча-писатель):
  - Диффузионный процесс: от шума к изображению
  - Энкодер-декодер: картинка → эмбеддинг → картинка
  - U-Net архитектура

#### Инструменты:
- **Midjourney:** художественная генерация, стилизация
- **Stable Diffusion:** локальная генерация, контроль
- **Flux:** передовая модель генерации
- **OCR-решения:** извлечение текста из документов

#### Практика:
- Генерация персонажей и стилей
- Создание консистентных изображений
- OCR: извлечение данных из документов

---

### Модуль 7: Мультимодальность: Звук и Голос
**4 ак.ч. лекция + 4 ак.ч. самостоятельная работа**

#### Теория:
- **Суперстимулы:** Тинберген, эволюция, педоморфные черты
- **Speech-to-Text (STT):**
  - Whisper от OpenAI: robustness, многоязычность
  - Спектрограммы и энкодер-декодер
  - Производительность: 1 мин аудио → 1 мин обработки
  - Стоимость: ~$0.50 за 3 часа
- **Text-to-Speech (TTS):**
  - Edge TTS: бесплатное озвучивание
  - Продвинутые модели: эмоции, интонации
- **Телефония:**
  - Twilio: VoIP, SIP, номера (~€1-2/мес)
  - WebSocket: двусторонний обмен аудио
  - Pipecat: фреймворк для голосовых агентов
- **Музыкальная генерация:**
  - Suno AI: вокал + инструменты, тексты песен
  - Warner Music: инвестиции в генеративную музыку

#### Применение:
- Транскрибация встреч и митингов
- Голосовые боты для бизнеса
- Озвучка книг и контента
- Генерация фоновой музыки

**4 ак.ч. лекция + 4 ак.ч. самостоятельная работа | Только BA-трек**

  - `git add .` — собрать изменения

Пользователь → Telegram → Raspberry Pi → AI-Агент → MCP → База Данных

## 💡 Ключевые принципы курса

1. **Фундаментальность > Инструменты** — принципы остаются, инструменты меняются
2. **Практика > Теория** — делаем MVP, а не "Звезду Смерти"
3. **Автоматизация > Ручной труд** — ИИ для рутины, человек для креативных задач
4. **Безопасность > Удобство** — Human-in-the-loop, бэкапы данных
5. **Архитектура > Код** — сначала понять процесс, потом автоматизировать
